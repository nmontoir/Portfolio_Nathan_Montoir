PORTFOLIO NATHAN MONTOIR
========================

OUVRIR LE SITE
  Double-clique sur index.html.

MODIFIER LES TEXTES (le plus simple)
  1. Ouvre index.html dans Chrome ou Edge.
  2. Tout en bas de la page, clique sur « Modifier les textes ».
  3. Clique sur n'importe quel texte encadré en pointillés et tape.
     Tu peux changer de page (accueil, fiches projet) sans rien perdre.
  4. Clique sur « Enregistrer contenu.js » et enregistre le fichier
     dans ce dossier, à la place de l'ancien contenu.js.
  5. Recharge la page (F5).

MODIFIER DAVANTAGE (ajouter un projet, une image, changer l'ordre)
  Tout le contenu est dans le fichier contenu.js. Ouvre-le avec le
  Bloc-notes ou VS Code.
  - Chaque projet est un bloc { ... } dans la liste "projets".
    Pour en ajouter un, copie un bloc existant et change son "id"
    (lettres minuscules, chiffres et tirets seulement).
  - L'ordre des projets dans le fichier est l'ordre sur le site.
  - Une fiche est une suite de "blocs" : texte, image, galerie,
    avant-apres, videos, code.
  - Pour ajouter une image : copie-la dans assets/img puis écris son
    chemin complet, par exemple  "img": "assets/img/ma-carte.jpg"
  - Dans un texte, \n\n crée un nouveau paragraphe.
  - Garde une copie de contenu.js avant de le modifier à la main :
    une virgule ou un guillemet oublié empêche le site de s'afficher.

REFAIRE LE PDF APRÈS UNE MODIFICATION
  1. Ouvre impression.html dans Chrome ou Edge.
  2. Clique sur « Imprimer / Enregistrer en PDF ».
  3. Destination : Enregistrer au format PDF. Mise en page : Paysage.
     Coche « Graphiques d'arrière-plan ».
  4. Enregistre sous assets/docs/Portfolio_Nathan_Montoir.pdf pour que
     le bouton « Télécharger le PDF » du site pointe sur la nouvelle
     version.

DEUX VERSIONS DE LA PAGE D'ACCUEIL
  index.html     la carte à côté du nom
  index_v2.html  la carte en pleine largeur, floutée derrière le texte
  Pour adopter la version pleine largeur dans index.html, ajoute dans
  contenu.js, à l'intérieur de "reglages" :
      "accueil": "pleine-page",
  La carte (assets/img/vil-salles-hero.webp, version décalée sans
  cartouche) est calée sur le bord droit de l'écran et dézoomée au
  maximum : sa hauteur est celle du bandeau. Deux réglages possibles
  dans "reglages" de contenu.js :
      "accueil_point": { "y": 0.505, "largeur_min": "76vw" },
  y : la hauteur de la carte à centrer verticalement (l'église).
  largeur_min : la largeur minimale de la carte sur les très grands écrans.

METTRE LE SITE EN LIGNE
  Le dossier fonctionne tel quel sur n'importe quel hébergement de
  pages statiques (GitHub Pages, Netlify...). Il suffit d'y déposer
  tout le contenu du dossier.

CONTENU DU DOSSIER
  index.html        le site
  contenu.js        tous les textes et la liste des projets
  impression.html   la version imprimable, pour créer le PDF
  assets/img        les cartes (xxx-m.jpg pour la page, xxx.webp pour le zoom)
  assets/video      les animations de Rufisque
  assets/docs       le PDF du portfolio, les rapports, le tutoriel, le script R
  assets/fonts      les polices
